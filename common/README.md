# Ansible Collection - keyvanakbary.common

An Ansible collection for installing Docker, creating a Docker Swarm, and
deploying Compose stacks.

## Roles

- `keyvanakbary.common.docker`
- `keyvanakbary.common.swarm`
- `keyvanakbary.common.compose`

System-level roles, including the MOTD role, live in the separate
`keyvanakbary.system` collection.
